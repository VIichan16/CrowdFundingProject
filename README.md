## 📌 프로젝트 소개 (About)

본 프로젝트는 창의적인 아이디어와 프로젝트를 가진 메이커(Maker)와 이를 응원하고 후원하는 서포터(Supporter)를 연결하는 **크라우드펀딩 플랫폼**입니다.

Java Socket을 활용한 TCP 클라이언트-서버 구조로 구현하였으며, 클라이언트는 서버에 접속하여 회원가입, 로그인, 프로젝트 조회 및 등록, 후원 등의 기능을 이용할 수 있습니다.

메이커는 프로젝트와 리워드를 등록하고 승인 신청 및 후원 현황을 확인할 수 있으며, 서포터는 프로젝트를 탐색하고 후원 및 리뷰를 작성할 수 있습니다. 관리자는 프로젝트 승인 및 거절을 통해 플랫폼을 운영합니다.

또한 Java Swing을 활용한 GUI 클라이언트를 제공하여 사용자가 그래픽 인터페이스를 통해 서비스를 이용할 수 있도록 구현하였습니다.

## 🔌 소켓 통신 구조 (Socket Architecture)

본 프로젝트는 Java의 TCP Socket을 활용한 클라이언트-서버 구조로 설계되었습니다.

클라이언트는 Socket을 통해 서버에 연결하고, 서버는 ServerSocket을 통해 클라이언트의 연결 요청을 수신합니다.

클라이언트가 요청 패킷을 전송하면 서버는 패킷을 분석하고 해당 요청을 처리한 후 결과를 응답 패킷으로 반환합니다.

### 통신 구성

| 구분 | 기술 및 역할 |
|---|---|
| Server | ServerSocket을 이용한 클라이언트 연결 수신 |
| Client | Socket을 이용한 서버 연결 및 요청 전송 |
| Protocol | TCP 기반 패킷 통신 프로토콜 |
| DataInputStream | 패킷 데이터 수신 |
| DataOutputStream | 패킷 데이터 전송 |
| ThreadPool | 여러 클라이언트의 요청 처리 |
| Encoding | UTF-8 기반 데이터 처리 |

### 패킷 구조

요청과 응답은 다음과 같은 고정 헤더 및 데이터 구조를 사용합니다.

| 구성 요소 | 크기 | 설명 |
|---|---:|---|
| TYPE | 2 Bytes | 요청 기능 구분 |
| CODE | 2 Bytes | 요청 및 처리 결과 코드 |
| LENGTH | 4 Bytes | 데이터 길이 |
| DATA | 가변 | UTF-8 인코딩 데이터 |

- Big-endian 방식 사용
- 헤더 크기: 8 Bytes
- 최대 데이터 크기: 65,536 Bytes
- 요청 및 응답 TYPE을 기준으로 기능 구분
- 로그인 상태는 TCP 연결별로 유지

### 주요 통신 TYPE

| TYPE | 기능 |
|---|---|
| 0x0001 | 로그인 |
| 0x0002 | 프로젝트 등록 |
| 0x0003 | 프로젝트 조회 및 검색 |
| 0x0004 | 프로젝트 후원 |
| 0x0005 | 프로젝트 좋아요 |
| 0x0006 | 리뷰 작성 및 수정 |
| 0x0007 | 프로젝트 수정 |
| 0x0008 | 리워드 등록 |
| 0x0009 | 프로젝트 승인 신청 |
| 0x000A | 후원 내역 조회 |
| 0x000B | 서포터 회원가입 |
| 0x000C | 메이커 프로젝트 현황 |
| 0x000D | 관리자 승인 및 거절 |
| 0x000E | 관리자 펀딩 현황 |
| 0x000F | 로그인 계정 정보 |
| 0x0010 | 프로젝트 목록 조회 |
| 0x0011 | 리워드 이미지 조회 |
| 0x0012 | 프로젝트 대표 이미지 조회 |

## 🗄️ 데이터베이스 (Database)

본 프로젝트는 관계형 데이터베이스인 MySQL을 기반으로 설계하였습니다.

주요 데이터는 다음과 같이 구성됩니다.

- 사용자 (Users)
- 프로젝트 (Project)
- 승인 이력 (Approval History)
- 리워드 (Reward)
- 후원 (Funding)
- 관심 프로젝트 (Project Like)
- 리뷰 (Project Review)

JDBC를 활용하여 서버와 MySQL을 연동하며, PreparedStatement를 통한 SQL 실행과 트랜잭션 관리를 적용하여 데이터의 일관성을 유지합니다.

특히 후원 처리 과정에서는 리워드 재고 관리와 동시성 제어를 고려하였습니다.

## ⚙️ 실행 방법 (Getting Started)

### 1. 실행 환경

- Java 17
- MySQL
- Gradle
- MySQL 데이터베이스 및 기존 프로젝트 스키마

### 2. 데이터베이스 설정

`src/main/resources/db.properties.example` 파일을 `db.properties`로 복사한 후 MySQL 연결 정보를 설정합니다.

서버에서 JDBC를 통해 데이터베이스에 연결합니다.

### 3. 소켓 서버 실행

터미널 1에서 다음 명령어를 실행합니다.

```bash
bash gradlew socketServer --console=plain
```

기본 포트는 `9090`입니다.

### 4. GUI 클라이언트 실행

새 터미널을 열고 다음 명령어를 실행합니다.

```bash
bash gradlew socketGui --console=plain
```

GUI 창이 실행되면 서버에 연결하여 서비스를 이용할 수 있습니다.

### 5. 콘솔 클라이언트 실행

GUI 대신 콘솔 환경을 사용하려면 다음 명령어를 실행합니다.

```bash
bash gradlew socketClient --console=plain
```

### 6. 패킷 테스트

데이터베이스 연결 없이 패킷 및 비로그인 권한 검사를 실행할 수 있습니다.

```bash
bash gradlew packetCheck
```
